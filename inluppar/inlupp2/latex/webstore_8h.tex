\doxysubsection{Detailed Description}
The webstore\+: the single object that holds all backend state. 

NOTE\+: The draft of the documentation for this module was created with Claude (Anthropic). It has been proofread and changed by us afterwards.

\begin{DoxyAuthor}{Author}
Markus Karlsson and Alva Fällman Nilsson 
\end{DoxyAuthor}
A webstore consists of three hash tables, which \doxylink{merch_8h}{merch.\+h} and \doxylink{cart_8h}{cart.\+h} operate on\+:
\begin{DoxyItemize}
\item merch\+\_\+ht\+: merch name (string) =\texorpdfstring{$>$}{>} \doxylink{merch_8h_a75fe011409c311da59f6fd00b869c668}{ioopm\+\_\+merch\+\_\+t} \texorpdfstring{$\ast$}{*}
\item cart\+\_\+ht\+: cart number (int) =\texorpdfstring{$>$}{>} \doxylink{cart_8h_ae72367f60488bfecb38a4cc93d809a62}{ioopm\+\_\+cart\+\_\+t} \texorpdfstring{$\ast$}{*}
\item storage\+\_\+ht\+: shelf name (string) =\texorpdfstring{$>$}{>} name of the merch stored on that shelf (string)
\end{DoxyItemize}

Create the store with ioopm\+\_\+webstore\+\_\+create when the program starts and pass a pointer to it to every backend function.
