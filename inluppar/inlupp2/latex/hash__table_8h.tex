\doxysubsection{Detailed Description}
Simple hash table that maps \doxylink{common_8h_a833876c3875048ad46fcc53f1246835e}{elem\+\_\+t} keys to \doxylink{common_8h_a833876c3875048ad46fcc53f1246835e}{elem\+\_\+t} values. 

\begin{DoxyAuthor}{Author}
Markus Karlsson \& Vilgot Lenninger 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
14/9-\/2026 
\end{DoxyDate}
Keys and values are stored as \doxylink{common_8h_a833876c3875048ad46fcc53f1246835e}{elem\+\_\+t} (see \doxylink{common_8h}{common.\+h}), so the table can hold ints, unsigned ints, bools, floats, strings or arbitrary pointers. The caller is responsible for knowing which field of the union a key or value was stored in.

Since a union carries no type information, the table cannot hash or compare keys on its own. Instead the caller passes a hash function and a key equality function to ioopm\+\_\+hash\+\_\+table\+\_\+create, and the table uses only these to decide which bucket a key belongs in and to find it within the bucket.

The table does not copy keys or values. Any memory that keys or values point to is owned by the caller, must outlive its mapping, and is never freed by the table.

The table grows automatically. When an insertion would make the number of entries divided by the number of buckets exceed the table\textquotesingle{}s load factor, the bucket array is enlarged and every entry is rehashed.
