\doxysubsection{Detailed Description}
Simple singly linked list of \doxylink{common_8h_a833876c3875048ad46fcc53f1246835e}{elem\+\_\+t} values. 

\begin{DoxyAuthor}{Author}
Markus Karlsson \& Vilgot Lenninger 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
28 Sep 2026 
\end{DoxyDate}
Elements are stored as \doxylink{common_8h_a833876c3875048ad46fcc53f1246835e}{elem\+\_\+t} (see \doxylink{common_8h}{common.\+h}), so the list can hold ints, unsigned ints, bools, floats, strings or arbitrary pointers. The caller is responsible for knowing which field of the union an element was stored in.

The list does not copy what elements point to. Any memory that elements point to is owned by the caller and is never freed by the list.
