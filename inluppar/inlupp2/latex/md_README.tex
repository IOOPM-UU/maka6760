A terminal webstore backend and menu-\/driven frontend, written in C. It manages merchandise, the shelves it is stored on, and shopping carts.\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{Build and test}{Build and test}}\label{md_README_autotoc_md1}

The tests cover the backend in {\ttfamily logic/}. The hash table and linked list are only tested indirectly through it, and {\ttfamily \doxylink{utils_8c}{utils.\+c}} and {\ttfamily interface/} read from the keyboard and have no unit tests.

In {\ttfamily \doxylink{linked__list_8c_a25eab8fdda3585d1460d91e67349994e}{ioopm\+\_\+list\+\_\+remove}} ({\ttfamily \doxylink{linked__list_8c}{linked\+\_\+list.\+c}}) the redundant condition {\ttfamily ioopm\+\_\+list\+\_\+size(list) == 1} is commented out, since it can never be false there, and would otherwise leave a branch that cannot be taken.\hypertarget{md_README_autotoc_md3}{}\doxysection{\texorpdfstring{Run the program}{Run the program}}\label{md_README_autotoc_md3}

\begin{DoxyCode}{0}
\DoxyCodeLine{make\ ui}

\end{DoxyCode}


This builds {\ttfamily ui\+\_\+c} and starts it. It can also be started directly with {\ttfamily ./ui\+\_\+c} after {\ttfamily make ui\+\_\+c}. The program takes no arguments and needs no input files\+: the store starts empty and everything is entered through the menu. Nothing is saved when the program quits.
