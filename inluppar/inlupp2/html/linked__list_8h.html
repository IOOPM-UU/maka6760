Detailed Description

Simple singly linked list of elem_t values.

Author
Markus Karlsson & Vilgot Lenninger
Date
28 Sep 2026

Elements are stored as elem_t (see common.h), so the list can hold ints, unsigned ints, bools, floats, strings or arbitrary pointers. The caller is responsible for knowing which field of the union an element was stored in.

The list does not copy what elements point to. Any memory that elements point to is owned by the caller and is never freed by the list.
