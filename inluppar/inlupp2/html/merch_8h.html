Detailed Description

Merchandise and its storage in the webstore.

NOTE: The draft of the documentation for this module was created with Claude (Anthropic). It has been proofread and changed by us afterwards.

Author
Markus Karlsson and Alva Fällman Nilsson

A merch has a name (unique in the store), a description, a price and a list of the shelves it is stored on. A shelf has a name and a quantity. A shelf name is one capital letter followed by two digits, e.g. "A01" (see ioopm_merch_is_shelf), and a shelf holds at most one kind of merch.

The merch in a store is kept in store->merch_ht, and which merch occupies which shelf is also kept in store->storage_ht. The functions here keep the two consistent, so use them instead of changing the tables directly.

Ownership: a merch owns its name and description, so these must be heap-allocated (e.g. with strdup) and are freed by ioopm_merch_destroy. Once a merch has been added to a store with ioopm_merch_add, it belongs to the store.
