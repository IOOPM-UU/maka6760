Detailed Description

The webstore: the single object that holds all backend state.

NOTE: The draft of the documentation for this module was created with Claude (Anthropic). It has been proofread and changed by us afterwards.

Author
Markus Karlsson and Alva Fällman Nilsson

A webstore consists of three hash tables, which merch.h and cart.h operate on:

  • merch_ht: merch name (string) => ioopm_merch_t *
  • cart_ht: cart number (int) => ioopm_cart_t *
  • storage_ht: shelf name (string) => name of the merch stored on that shelf (string)

Create the store with ioopm_webstore_create when the program starts and pass a pointer to it to every backend function.
