Detailed Description

The terminal user interface for carts.

NOTE: The draft of the documentation for this module was created with Claude (Anthropic). It has been proofread and changed by us afterwards.

Author
Markus Karlsson and Alva Fällman Nilsson

Each function is one entry in the main menu of the program: it asks the user for what it needs on stdin, calls the matching backend function in cart.h and prints the result. The functions never fail; problems such as an unknown cart number are reported to the user as a message.
