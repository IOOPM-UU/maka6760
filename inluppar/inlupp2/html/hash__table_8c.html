◆ ioopm_hash_table_create()

ioopm_hash_table_t * ioopm_hash_table_create ( ioopm_hash_function * hash_fn,
ioopm_eq_function * key_eq_fn )

Create a new hash table.

Parameters
hash_fnfunction that computes a hash value for a key. Used to decide which bucket a key belongs in
key_eq_fnfunction that returns true if two keys are equal. Used to find the right entry within a bucket
Precondition
keys that key_eq_fn considers equal must get the same value from hash_fn, otherwise they may end up in different buckets and not be found
key_eq_fn and hash_fn must read the same field of the union as the keys are stored in (e.g. .s for string keys, .i for int keys)
Returns
A new empty hash table with 17 buckets and load factor 0.75

Parameters

Precondition

load_factor > 0
same requirements on hash_fn and key_eq_fn as for ioopm_hash_table_create
Returns
